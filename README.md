# Now Playing

OBS Studio の **VLCビデオソースで現在再生している楽曲情報を、テキストソースへ自動表示する Lua スクリプト**です。

VLCビデオソースに `.m3u` プレイリストを設定している場合だけでなく、MP3 などの音声ファイルを複数直接追加している場合にも使用できます。

> 通常の「メディアソース」ではなく、**VLCビデオソース**を対象にしています。

> **非公式ツールです。** このプロジェクトは OBS Project および VideoLAN と提携・承認・後援関係にありません。OBS Studio、VLC および関連名称は、それぞれの権利者に帰属します。本文中の名称は、対応環境や機能を説明する目的で使用しています。

## ファイル

### `now_playing.lua`

普段使う本体です。

VLCビデオソースで再生中の楽曲からメタデータを取得し、指定したOBSテキストソースへ表示します。

### `metadata_probe.lua`

メタデータ確認用の診断ツールです。

「曲名が表示されない」「Artist と Album Artist のどちらに情報が入っているか分からない」といった場合に、OBS のスクリプトログへ取得結果を出して確認できます。

通常は手動取得のみで使用し、**自動監視は初期状態でOFF**です。自動監視をONにしても、OBS再起動・スクリプト再読み込み時にはOFFへ戻ります。

---

## 主な機能

- VLCビデオソースで現在再生中の楽曲を自動検出
- `.m3u` プレイリストに対応
- VLCビデオソースへ複数の音声ファイルを直接追加する構成にも対応
- 曲名 / アーティスト / アルバム / 年 / ジャンルを選択して表示
- `Album Artist → Artist` など、アーティスト情報の優先順を選択可能
- メタデータが空の項目は自動的に除外
- 同じ内容が複数タグに入っている場合は重複表示を抑制
- 改行 / ` / ` / ` - ` / ` | ` から区切り方法を選択
- 先頭に `♪ ` など任意の文字を追加可能
- 停止・終了時に表示を消す設定
- 曲切り替え時の一時的な空データや、旧曲・新曲のタグ混在を抑制
- 表示先テキストソースをシーンごとに整理して表示

## 安全対策

**表示先テキストソースは自動選択しません。**

初期状態は必ず、

```text
（選択なし）
```

です。

ユーザーが明示的に表示先を選択するまでは、既存のテキストソースを書き換えません。

これは、スクリプトを追加しただけで意図しないテキストソースが曲名表示に書き換わる事故を防ぐためです。

---

## 導入方法

1. `now_playing.lua` をダウンロードします。
2. OBS Studio を開きます。
3. **ツール → スクリプト** を開きます。
4. `+` を押して `now_playing.lua` を追加します。
5. 「VLCビデオソース」からBGMを再生しているソースを選択します。
6. 「表示先テキストソース」から、曲情報を書き込むテキストソースを選択します。
7. 表示したい項目や区切り方法を設定します。

## 表示例

初期設定では、曲名とアーティストを改行して表示します。

```text
♪ Sample Track
Example Artist
```

区切りを ` / ` に変更すると、

```text
♪ Sample Track / Example Artist
```

のように一行表示もできます。

## 取得するメタデータ

本体では主に以下を利用します。

| 項目 | VLCメタデータ |
|---|---|
| 曲名 | `title` |
| 曲名の代替 | `now_playing` |
| アーティスト | `artist` |
| アルバムアーティスト | `album_artist` |
| アルバム | `album` |
| 年 | `date` |
| ジャンル | `genre` |

楽曲ファイルによって、設定されているタグは異なります。

そのためアーティストについては、

- Album Artist → Artist
- Artist → Album Artist
- Artist のみ
- Album Artist のみ

から取得方法を選べます。

また、選択した項目のタグが空の場合、その項目は表示から自動的に除外されます。

### タグがすべて空の場合

「タグがすべて空の場合」の欄に、

```text
♪ BGM再生中
```

などを設定しておくこともできます。

空欄のままにすることも可能です。

## VLCビデオソースのプレイリストについて

次のどちらでも利用できます。

### M3Uプレイリスト

```text
playlist.m3u
  ├─ track01.mp3
  ├─ track02.mp3
  └─ track03.mp3
```

### 音声ファイルを直接追加

OBS の VLCビデオソースへ、

```text
track01.mp3
track02.mp3
track03.mp3
```

のように複数ファイルを直接追加した場合も利用できます。

このスクリプトは M3U ファイルそのものを解析しているのではなく、**VLCが現在再生しているメディアからメタデータを取得しています。**

---

## メタデータを確認する

表示がおかしい場合は、`metadata_probe.lua` を使用してください。

1. **ツール → スクリプト** から `metadata_probe.lua` を追加
2. 対象のVLCビデオソースを選択
3. **今すぐメタデータを取得** を押す
4. OBS のスクリプトログを確認

例:

```text
title        : Sample Track
artist       : Example Artist
album        : Sample Album
album_artist : Example Artist
date         : 2026
```

### 自動監視

必要な場合のみ「自動監視」をONにできます。

- 1秒ごとに確認
- 内容が変化した場合のみログ出力
- 初期状態はOFF
- OBS再起動・スクリプト再読み込み時はOFFへ戻る

診断が終わったらOFFのままにしておくことをおすすめします。

## 対応環境

開発・動作確認:

- OBS Studio 32.2.2
- macOS

現在のスクリプトは、シーン内グループのテキストソースを列挙するOBS scripting APIを使用しているため、**OBS Studio 28.1以降を想定**しています。

OBS 27.x以前では、VLCメタデータ取得自体が利用できる場合でも、現在のUI列挙処理を含めて正常動作することは保証していません。

Windows / Linux についても、OBS標準のテキストソースを対象にする実装ですが、現時点では作者環境での実機確認は macOS が中心です。

---

## 注意事項

- 対象は **VLCビデオソース** です。通常の「メディアソース」は現在未対応です。
- 楽曲ファイルにメタデータが設定されていない場合、曲名やアーティスト名を取得できないことがあります。
- ファイル名から必ず曲名を復元する機能は現在ありません。
- 表示先として選択したテキストソースの内容は、このスクリプトによって更新されます。
- 同じテキストソースを他のスクリプトや自動化処理と共有すると、互いに内容を書き換える可能性があります。

## トラブルシューティング

### 曲名が表示されない

`metadata_probe.lua` で `title` や `now_playing` が取得できているか確認してください。

### アーティスト名がおかしい

楽曲によって `artist` と `album_artist` の使い方が異なります。

「アーティストの取得元」を変更して確認してください。

### 表示先が一覧で見つけにくい

表示先テキストソースはシーンごとに整理して表示します。

シーン内のグループに入っているテキストソースも、そのシーン配下として列挙します。

### 曲切り替え時に一瞬表示が消える

曲間の短い停止状態ではすぐに表示を消さないよう、連続して停止状態を検出した場合にのみクリアする処理を入れています。
