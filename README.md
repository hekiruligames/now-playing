# Now Playing

OBS Studio の **VLCビデオソースで現在再生している楽曲情報を、OBS標準テキストソースへ自動表示する Lua スクリプト**です。

Now Playing は、テキストソースへ追加する **フィルタ** として動作します。  
テキストソースごとに監視するVLCビデオソースと表示形式を個別に設定できるため、複数シーン・複数BGM構成でも独立して利用できます。

VLCビデオソースに `.m3u` プレイリストを設定している場合だけでなく、MP3 などの音声ファイルを複数直接追加している場合にも使用できます。

> 通常の「メディアソース」ではなく、**VLCビデオソース**を対象にしています。

> **非公式ツールです。** このプロジェクトは OBS Project および VideoLAN と提携・承認・後援関係にありません。OBS Studio、VLC および関連名称は、それぞれの権利者に帰属します。本文中の名称は、対応環境や機能を説明する目的で使用しています。

## ファイル

### `now_playing.lua`

普段使う本体です。

OBS標準テキストソースへ `Now Playing` フィルタを追加し、そのフィルタから監視するVLCビデオソースを選択します。

### `metadata_probe.lua`

メタデータ確認用の診断ツールです。

「曲名が表示されない」「Artist と Album Artist のどちらに情報が入っているか分からない」といった場合に、OBS のスクリプトログへ取得結果を出して確認できます。

通常は手動取得のみで使用し、**自動監視は初期状態でOFF**です。自動監視をONにしても、OBS再起動・スクリプト再読み込み時にはOFFへ戻ります。

---

## 主な機能

- OBS標準テキストソースへ `Now Playing` フィルタとして追加
- フィルタごとに監視するVLCビデオソースを個別設定
- 複数シーン・複数テキストソースで独立した設定を保持
- 同じVLCビデオソースを複数のNow Playingフィルタから参照可能
- Luaスクリプト全体で1本の監視タイマーを使用
- VLCビデオソースで現在再生中の楽曲を自動検出
- `.m3u` プレイリストに対応
- VLCビデオソースへ複数の音声ファイルを直接追加する構成にも対応
- 曲名 / アーティスト / アルバム / 年 / ジャンルを選択して表示
- `Album Artist → Artist` など、アーティスト情報の優先順を選択可能
- メタデータが空の項目は自動的に除外
- 同じ内容が複数タグに入っている場合は重複表示を抑制
- 改行 / ` / ` / ` - ` / ` | ` から区切り方法を選択
- 先頭に `♪ ` など任意の文字を追加可能
- 停止・終了時に表示を消す設定
- 曲切り替え時の一時的な空データや、旧曲・新曲のタグ混在を抑制

## 安全対策

表示先テキストソースをドロップダウンから選択する方式ではありません。

Now Playing は **フィルタを追加したテキストソース自身**だけを書き換えます。そのため、別のテキストソースを誤って表示先として選択する操作がありません。

また、監視するVLCビデオソースの初期値は、

```text
（選択なし）
```

です。

VLCビデオソースを明示的に選ぶまでは、楽曲情報の取得・表示更新を開始しません。

## 導入方法

1. `now_playing.lua` をダウンロードします。
2. OBS Studio を開きます。
3. **ツール → スクリプト** を開きます。
4. `+` を押して `now_playing.lua` を追加します。
5. 楽曲情報を表示したい **OBS標準テキストソース** のフィルタ画面を開きます。
6. `+` から **Now Playing** を追加します。
7. 「監視するVLCビデオソース」からBGMを再生しているVLCビデオソースを選択します。
8. 表示したい項目や区切り方法を設定します。

### 複数シーンで使う場合

各シーンのテキストソースに、それぞれNow Playingフィルタを追加します。

```text
作業配信
└─ Text: BGM表示
   └─ Filter: Now Playing
      └─ VLC Source: 作業用BGM

ゲーム配信
└─ Text: BGM表示
   └─ Filter: Now Playing
      └─ VLC Source: ゲーム用BGM
```

各フィルタの設定は独立しています。

同じVLCビデオソースを、複数のテキストソースから参照することもできます。

> 1つのテキストソースへ複数のNow Playingフィルタを追加すると、同じテキスト内容を複数のフィルタが更新することになります。通常は **1テキストソースにつき1つ** のNow Playingフィルタを使用してください。

## 表示例

初期設定では、曲名とアーティストを改行して表示します。

```text
♪ Sample Track
Example Artist
```

区切りを ` / ` に変更すると、

```text
♪ Sample Track / Example Artist
```

のように一行表示もできます。

## 取得するメタデータ

本体では主に以下を利用します。

| 項目 | VLCメタデータ |
|---|---|
| 曲名 | `title` |
| 曲名の代替 | `now_playing` |
| アーティスト | `artist` |
| アルバムアーティスト | `album_artist` |
| アルバム | `album` |
| 年 | `date` |
| ジャンル | `genre` |

楽曲ファイルによって、設定されているタグは異なります。

そのためアーティストについては、

- Album Artist → Artist
- Artist → Album Artist
- Artist のみ
- Album Artist のみ

から取得方法を選べます。

また、選択した項目のタグが空の場合、その項目は表示から自動的に除外されます。

### タグがすべて空の場合

「タグがすべて空の場合」の欄に、

```text
♪ BGM再生中
```

などを設定しておくこともできます。

空欄のままにすることも可能です。

## VLCビデオソースのプレイリストについて

次のどちらでも利用できます。

### M3Uプレイリスト

```text
playlist.m3u
  ├─ track01.mp3
  ├─ track02.mp3
  └─ track03.mp3
```

### 音声ファイルを直接追加

OBS の VLCビデオソースへ、

```text
track01.mp3
track02.mp3
track03.mp3
```

のように複数ファイルを直接追加した場合も利用できます。

このスクリプトは M3U ファイルそのものを解析しているのではなく、**VLCが現在再生しているメディアからメタデータを取得しています。**

---

## メタデータを確認する

表示がおかしい場合は、`metadata_probe.lua` を使用してください。

1. **ツール → スクリプト** から `metadata_probe.lua` を追加
2. 対象のVLCビデオソースを選択
3. **今すぐメタデータを取得** を押す
4. OBS のスクリプトログを確認

例:

```text
title        : Sample Track
artist       : Example Artist
album        : Sample Album
album_artist : Example Artist
date         : 2026
```

### 自動監視

必要な場合のみ「自動監視」をONにできます。

- 1秒ごとに確認
- 内容が変化した場合のみログ出力
- 初期状態はOFF
- OBS再起動・スクリプト再読み込み時はOFFへ戻る

診断が終わったらOFFのままにしておくことをおすすめします。

## v1.2 からの変更

v1.2 では、**ツール → スクリプト** の設定画面で、

- VLCビデオソース
- 表示先テキストソース

を1組だけ設定していました。

v2系では、設定場所が **各テキストソースのNow Playingフィルタ** に変わります。

そのため、v1.2 のスクリプト設定はv2系のフィルタ設定へ自動移行されません。更新後は、楽曲情報を表示したいテキストソースへNow Playingフィルタを追加し、監視するVLCビデオソースを設定してください。

## 対応環境

開発・実機確認:

- OBS Studio 32.2.2
- macOS

現在は **OBS Studio 28.1以降を想定**しています。

フィルタ登録、ソース列挙、タイマー、VLCメタデータ取得などOBS scripting APIを利用しています。OBS 27.x以前は現在の対象外です。

Windows / Linux についても、OBS標準のテキストソースを対象にする実装ですが、現時点では作者環境での実機確認は macOS が中心です。

## 実機検証

OBS Studio 32.2.2 / macOS で、以下を確認しています。

- 標準テキストソースへNow Playingフィルタを追加
- 2つのフィルタで別々のVLCビデオソースを選択
- 複数構成の独立動作
- 曲切り替え時の表示更新
- Album Artist欠落時のArtistフォールバック
- 区切り・接頭辞の個別設定
- VLC停止時の表示クリア
- フィルタ無効化・再有効化
- フィルタ削除・再追加
- スクリプト再読み込み後の設定・表示復帰

## 注意事項

- 対象は **VLCビデオソース** です。通常の「メディアソース」は現在未対応です。
- 楽曲ファイルにメタデータが設定されていない場合、曲名やアーティスト名を取得できないことがあります。
- ファイル名から必ず曲名を復元する機能は現在ありません。
- Now Playingフィルタを追加したテキストソースの内容は、このスクリプトによって更新されます。
- 同じテキストソースを他のスクリプトや自動化処理と共有すると、互いに内容を書き換える可能性があります。

## トラブルシューティング

### フィルタ一覧に Now Playing が表示されない

**ツール → スクリプト** で `now_playing.lua` が読み込まれているか確認してください。

### 曲名が表示されない

Now Playingフィルタで監視するVLCビデオソースが選択されているか確認してください。

そのうえで `metadata_probe.lua` を使い、`title` や `now_playing` が取得できているか確認してください。

### アーティスト名がおかしい

楽曲によって `artist` と `album_artist` の使い方が異なります。

「アーティストの取得元」を変更して確認してください。

### 曲切り替え時に一瞬表示が消える

曲間の短い停止状態ではすぐに表示を消さないよう、連続して停止状態を検出した場合にのみクリアする処理を入れています。
